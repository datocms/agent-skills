# Concise skill prose

Keep instructions short and readable. Remove filler, repeated rules, and generic explanations that do not change the agent's decisions. Preserve non-obvious constraints, working examples, paths, commands, and API details.

Use plain sentences where compressed fragments would be ambiguous. Keep topic details in selectively loaded references. A short contents section is useful for long references when it helps locate the needed information.

Do not run bulk compression as part of routine maintenance or a structural migration. The existing compression scripts are optional tools, not a required publishing step.
