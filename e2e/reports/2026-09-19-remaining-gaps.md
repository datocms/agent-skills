The canonical Nuxt controller example now updates its path in `router.afterEach`, before rendering, and owns its routing callback so parent listeners cannot merge into a non-callable array. A fresh setup later omitted the controller and invoked the browser subscription during SSR; a local transport probe reproduced `window is not defined` before any request. The Nuxt introduction now links directly to the required controller and client-only subscription examples. The second fresh setup lost request context after an awaited import and returned Nuxt E1001 on public reads. A later fresh implementation repeated the same request-context failure. Both remain failed attempts; the Nuxt reference now states that context helpers must run before awaiting, and frontend verification requires served-page checks as well as a build.
