## Props

### DisclosureChevron

| Prop | Type | Required | Default | Description |
| - | - | - | - | - |
| `open` | `boolean` | Yes | | True when the content is open. The chevron turns down. |
| `className` | `string` | No | | A class for the position of the chevron (margin, alignment) |

### MenuChevron

| Prop | Type | Required | Default | Description |
| - | - | - | - | - |
| `className` | `string` | No | | A class for the position of the chevron (margin, alignment) |

### LoadMoreChevron

| Prop | Type | Required | Default | Description |
| - | - | - | - | - |
| `loading` | `boolean` | No | `false` | True while the items load. A spinner shows instead of the chevron, with the same size. |
