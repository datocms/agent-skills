2. Reuse the established project and environment. Resolve missing targets through the available tools; ask only when the intended target remains ambiguous. Before updating, emit the original fields, locales, references, and publication state needed for verification as reusable code: `console.log("const before = " + JSON.stringify(snapshot) + ";")`. Script variables do not persist between executions; flags and counts cannot replace original values.
5. Verify in a separate read-only script, copying the generated snapshot exactly, including escape sequences. Do not retype strings, double-escape newlines, invent originals, or substitute example constants. Compare meaningful saved values, not `serialize()` output or whole-tree request/response equality. 6. Apply the task's existing CMA reference and preserve unrelated content. Keep nested Structured Text response snapshots separate from request values. Use optional access for marks and link metadata; unmarked spans accept omitted or empty marks with `(span.marks?.length ?? 0) === 0`. Reuse guidance already returned by MCP; load references only for missing task knowledge. CLI documentation hints apply only to CLI execution.
7. A timeout or missing response does not prove a write failed: inspect its outcome before retrying, and never repeat an uncertain write through a different route. Authentication and permission errors are not reasons to bypass the selected connection.
